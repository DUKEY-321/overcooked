# 来源与许可记录

每个外部模型、纹理、字体、图片或角色形象使用一份由 `ATTRIBUTION_TEMPLATE.md` 复制出的记录。原始许可页面截图、许可文本副本和来源文件 SHA-256 应放在对应角色的 `references/` 中。

公开发布和测试时至少确认：

- 上传者是否有权许可该素材；
- 许可是否允许修改、游戏 MOD 使用和再分发；
- 是否要求署名、同许可发布或禁止商用；
- 角色形象、商标等底层权利是否需要额外许可；
- 最终压缩包内是否需要附带许可文本。

不要凭记忆填写许可，也不要把“仅供参考”写成“已获授权”。不确定项保留为 `PENDING`，并在 README 和 Release 中明确披露。当前发布范围见 `DISTRIBUTION_NOTICE.md`。
